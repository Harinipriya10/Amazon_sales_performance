Amazon_Sales_Performance_Dashboard

This project is an interactive Power BI dashboard built to analyze Amazon sales data. It provides deep insights into product performance, regional trends, profit analysis, and time-based sales dynamics.


Objectives:
• To Analyze sales by product, region, and category
• To Track performance over time using order dates
• To Identify top-performing and underperforming products
• To Provide actionable insights using interactive visuals




1) Data Source (Excel) - Kaggle
2) Data Cleaning (Python)
3) Data Visualization (PowerBI)
